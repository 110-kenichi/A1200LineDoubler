# 主要ICへの電源分配 v0.22

2026-09-20。v0.21の電源部から、ADC・FPGA・DACとその電源コンデンサへ配線を延長した。**部分配線のレビュー版。基板全体の製造判定は未完了。** 95×95mm・4層・135部品を維持し、回路・部品・FPGAロジックは変更していない。

## 追加した配線

ADCの16電源端子、FPGAの11電源端子、DACの3電源端子を、それぞれ既存の近傍コンデンサへ配線した。計30組。電源ネットは3.3V、1.9V、1.2Vと、FB1〜FB4で分離されるADCアナログ3.3V、ADCアナログ1.9V、ADC PLL1.9V、DAC3.3Vの7種類。フィルター前後のネットを混同せず、各コンデンサとフィルター端子を電源元まで接続した。

コンデンサと各ICのGND端子をビア経由でIn1.Cuの連続GND面へ接続した。ADC・FPGAの露出パッドも電気的にGNDへ接続している。ただし、現在の露出パッドの細い配線は電気接続の検討段階であり、放熱設計を満たす根拠にはしない。放熱ビア、はんだ流出対策、実装方式を含む最終設計が別途必要。

端子周辺の配線幅は0.15mm、追加した電源の分配線は0.40mm、貫通ビアは径0.60mm／穴0.30mm。分配は主にIn2.Cu、一部B.Cuを使用した。端子とコンデンサ間の最長配線は約5.384mm。この距離とGNDへの帰路を、実負荷・周波数で良好なデカップリングが得られる根拠とはしない。必要なら部品配置と配線幅を再調整する。

コンデンサと電源・GNDの配置条件の最終確認には、[TI TVP7002データシート](https://www.ti.com/lit/ds/symlink/tvp7002.pdf)と[Analog Devices ADV7125データシート](https://www.analog.com/media/en/technical-documentation/data-sheets/ADV7125.pdf)を参照する。今回確認したのは幾何学的な間隔と電気接続であり、電源インピーダンス・電圧降下・温度上昇・ノイズの合格ではない。

## 検査結果

KiCad 7が持つ実際のパッド・配線・ビアの接続情報をたどって検査した。配線を生成した処理の「成功」表示だけで接続完了と判断していない。

- 前版の電源部57組を再検査して接続維持を確認。
- 75組の電源接続を確認。IC端子から電源元までと、コンデンサ・フィルター端子を含む。
- 80か所のGND接続を確認。GNDビアが単一の内層GND領域内にあることを検査。
- 全135部品・592パッドのネット割り当てが回路定義と一致。
- 銅箔間隔、短絡、穴周辺、穴同士の間隔、コートヤード、未接続ビア、ソルダーマスクのブリッジは0件。クリアランス0.20mmを維持し、DRC除外の追加や規則の緩和は行っていない。

現在の基板は配線区間1,369本、貫通ビア117本。未接続件数は365から217へ減少した。これはKiCadのラッツネスト件数であり、未完了ネット数や進捗率ではない。

**全体DRCは未合格。** 未接続217件のほか、文字高さ135件、シルクと銅箔の重なり72件、シルク同士の重なり27件、シルクと基板端の間隔2件が残る。`hardware/distribution_drc.txt` と `hardware/distribution_report.json` に結果を保存した。

## 現行ファイル

- `hardware/amiga_scandoubler_distribution.kicad_pcb` と同名の `.kicad_pro` が現在の部分配線基板。
- `distribution_review.png/svg` が全体図、`distribution_detail.png` が主要IC周辺の拡大図。F.Cuは赤、B.Cuは青、In2.Cuは橙。GND面のIn1.Cuはプレビューから省略。
- `hardware/distribution_progress.json` は生成した個別配線の経路・長さ・ビア位置の記録。完成判定には独立した `distribution_report.json` とDRC報告を併用する。
- `hardware/amiga_scandoubler_routing.kicad_pcb` はv0.21の電源部だけの配線履歴。部品配置はそこから変えていない。

KiCad 7付属Pythonで、以下を実行できる。標準ライブラリを指す `KICAD7_FOOTPRINT_DIR` の設定も必要。

```
python hardware/scripts/build_distribution.py
python hardware/scripts/audit_distribution.py
```

生成処理はv0.21の基板から現行の部分配線を再作成する。現行ファイルへ後から追加した手配線は上書きされるため、監査だけ行う場合は後者のみを使う。配線候補は障害物を避けて生成し、その後にKiCadの接続とDRCを検査する。配線長・波形・電源品質を自動で最適化したものではない。

## 残作業

RGB、クロック、H/V、I²C、JTAG、POWER_GOODからFPGA、入力バッファ・同期出力バッファ・発振器周辺などの配線が残る。DACのCOMP/VREF/RSET、ADCのPLLフィルターなども未完了。主要ICの電源配線がつながったことを、通電して動作する基板の完成とは扱わない。

放熱設計、電源・GNDの帰路の最終確認、実負荷での電圧降下とリップル、シルク整理、フットプリント・部品調達・実装条件の最終確認が必要。FPGAの実入力プロファイル、長短ライン処理、外部タイミング、実機確認も引き続き未完了。現行FPGA実装は `implementation/output_release/` のまま。製造用Gerber、完成BOM/CPL、実機ビットストリームは未生成。
