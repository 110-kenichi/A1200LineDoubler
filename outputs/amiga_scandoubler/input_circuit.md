# 入出力回路の接続案

設計検討版。ここに示す接続を完成回路図・製造ネットリストとして扱わないこと。部品番号と端子番号は採用する正確な型番のデータシートで最終照合する。

## J1：Amiga側DE-15メス

標準VGA配列を仮定。利用者のアダプター説明はUNBUFFERED H/Vであり、実配線の証明にはならない。接続前に少なくともH/V、GND、電源ピンの導通を確認する。

| J1端子 | 基板内の接続案 |
|---|---|
| 1 R | 入力点から75ΩでGND終端、100nF直列AC結合→TVP7002 RIN_1（11番） |
| 2 G | 同じ終端・AC結合→GIN_1（2番） |
| 3 B | 同じ終端・AC結合→BIN_1（18番） |
| 5、6、7、8、10 | GND。RGB帰路は対応する信号経路に近接させる |
| 13 H | 直列抵抗候補33Ω→SN74LVC2G17→HSYNC_A（81番） |
| 14 V | 直列抵抗候補33Ω→SN74LVC2G17→VSYNC_A（78番） |
| 4、9、11、12、15 | 入力側は未接続。USBの5VをAmiga側へ供給しない |
| シェル | 基板GNDへの接続とESD帰路をレイアウト時に確定 |

75Ω終端は映像RGB用。H/Vを75Ωで終端しない。同期受信バッファの電源は3.3V、近接100nFを設ける。同期入力には弱いプルアップを検討して、未接続時の浮きを抑える。クランプ保護素子は通常の5V同期をクランプしない仕様を選定する。

SN74LVC2G17は5.5V入力許容と部分電源断時のIoffを持つ候補。TVP7002のデジタル入力の絶対最大は4.5Vなので、Amigaの5V系同期を直接TVP7002へつながない。

## TVP7002の周辺回路

- RIN_2/3、GIN_2/3/4、BIN_2/3：未使用入力の処理は各10nF経由GND。
- SOGIN_1/2/3：使用しない場合は各1nF経由GND。
- HSYNC_B、VSYNC_B、TMS：GND。CLAMP/COASTは内部生成を使う場合の推奨処理に従う。
- FILT1（87番）→100nF＋1.5kΩ直列→PLL_F（89番）。FILT2（88番）→4.7nF→PLL_F。PLL_FはGNDではない。
- A33VDD/IOVDD：3.3V。AVDD/DVDD/PLL_AVDD：1.9V。全電源端子のデカップリング、放熱パッドのGND接続とサーマルビアを設計する。
- I²C：SCL（74番）、SDA（75番）、3.3Vへのプルアップ候補2.2kΩ。I2CA（73番）をLowにすると、7bitアドレスは0x5C（データシートの0xB8は書き込みアドレスバイト）。
- RESETB（71番）は電源安定後までLow。I²C初期化に先立って所定のリセット時間を確保。PWDN（70番）と併せて起動順を制御。
- DATACLK（28番）をFPGAのPLL入力対応端子へ接続。HSOUT（24番）、VSOUT（23番）、FIDOUT（22番）のうち必要な出力を取り込む。
- RGBは各上位8bitを候補とする。出力フォーマット設定とバス上のビット位置を照合してから24本の接続を確定する。

## J2：モニター側DE-15メス

| J2端子 | 接続方針 |
|---|---|
| 1、2、3 | DACのR/G/B。モニター側75Ω負荷時の白レベル約0.7V |
| 5、6、7、8、10 | GND |
| 13、14 | FPGAで生成した31kHz系H/V。出力バッファ＋直列ダンピング抵抗 |
| 9 | 現段階では未確定。DDC電源の必要性と電流制限を検討 |
| 12、15 | DDCは機能必須ではない。未接続案を基本とし、モニター検出条件を確認 |
| 4、11 | 未接続 |

ADV7125は電流出力DACであり、一般的な電圧出力の直列75Ω回路をそのまま適用しない。DAC側75Ω並列終端とモニター75Ωの合成37.5Ω負荷なら、0.7Vに必要な電流は約18.67mA。データシートの基準・ゲイン式と許容電流を照合し、RSETは約530Ω近傍から検討する。これを確定値として発注しない。

SYNCはRGBに同期を重畳しない設定に固定し、H/Vを別に出力。BLANKとDACのクロック遅延に合わせてH/Vをパイプライン調整する。未使用の相補DAC出力、VREF、COMP、PSAVEはメーカー推奨回路を適用する。
