# v0.29 FPGA（U2）180°回転＋REF_27M配線（2026-09-27, Claude）

基準：v0.28 `amiga_scandoubler_sync_in.kicad_pcb` → 本版 `hardware/amiga_scandoubler_u2rot.kicad_pcb`（KiCad 7形式のまま）。
**製造可能な完成品ではない。未接続143件。**

## 理由

FPGAのピン割当（`constraints/amiga_board_top.cst`）は、ADC入力が右辺・上辺（IOR/IOT、ADC_CLKはRPLL_T_inの63番）、DAC出力が左辺・下辺（IOL/IOB）だった。一方、実配置はADC（U1）がFPGAの左、DAC（U3）が右。このため24bit×2のバスとADC_CLKがすべてFPGAを回り込む構成だった。
ピン割当と検証済みの合成・配置配線結果を変えずに解消するため、U2を180°回転した。直線近似の評価では、配線がチップ本体を横切る本数が74→53、交差数が411→262に減る。ADC_CLKの端子間距離は約45mm（FPGA外周を半周）から約24mm（U1とU2の対向面の間）に縮む。

## 変更内容

| 対象 | 内容 |

| U2＋周辺18部品 | U2、C29–C41、R2、R3、R4、R9を中心(50,42)で剛体的に180°回転。周辺の配線とビア（F/B/In2の262区間、28ビア）も同じ変換で移動。各パスコンと電源ピンの対応はそのまま |

| H_OUT_RAW / V_OUT_RAW | 60/61番ピンが左辺へ移ったため再配線。QFN内周のビア → B.Cu（U2下辺の外側）→ R41/R42。H 45.4mm、V 43.8mm、各ビア4個 |

## 検査（KiCad 10.0.4）

- `work/audit_sync_in.py`（環境変数 BOARD/TAG で対象基板を指定できるよう変更）：**PASS**。既存57接続、電源75・GND80検査、592パッドのネット照合、入出力同期12ネット導通、PLL 4ネットはF.Cuのみ・ビア0を維持。
- DRC：短絡・クリアランス・穴間隔・コートヤード・配線端/ビア未接続 **0件**。未接続 146→143（REF_27M系3件が完了。v0.28比で増えたネットなし）。
- In1 GND面は再充填した充填形状をKiCad 7形式へ移植済み。

## 判明した課題（次の作業）

1. **U1下辺からの信号の引き出し**：U1下辺のピン（ADC_CLK=28、B7–B0、G7–G0）の直下を、パスコンC19、C64、C20、C21、C65と、ピン27のGNDビアが塞いでいる。裏面（B.Cu）も、H/V_IN_3V3の斜め配線とADC 1.9V電源の太い斜め配線が壁になっている。このためADC_CLKもデータバスも素直に引き出せない。
   → U1下辺のパスコンの配置を見直し、ピン列の直下に3–4mmの引き出し帯を確保してから、ADC_CLKとG/Bバスを配線する。
2. 回転に伴い、I2C（13/14）、ADC_RESET_N（15）、JTAG（5–8）、DONE、RECONFIGがU2右辺に移った。U1やJ4へは裏面を経由して戻す（いずれも低速信号）。
3. DAC側（U3）は上辺R・左辺G・下辺Bで、U2上辺から来るバスに対しては、下辺のBの戻りが残る。U3の回転は、バス配線の前に再評価する。
