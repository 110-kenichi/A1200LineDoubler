## 2026-09-28 C34 の孤立を解消（KiCad 7.0.11、クラウドセッション）

**変更内容**
- C34（100nF、0603。U2 の 3V3 パスコン）を (37,30) から (45.4,49.15) へ移した。
  - 向きは 270° で、pad1（3V3）が上、pad2（GND）が下。
- pad1 から U2.67 の既存 3V3 ビア (45.6,47.6) へ、F.Cu 0.25mm の配線を1本引いた。
- pad2 から F.Cu 0.25mm の配線を引き、GND ビア (45.4,50.875)（0.6/0.3）を追加した。
- リファレンスのシルク文字を (43.5,50.3) の横向きに置いた。C30 の文字とは重ならない。
- In1 と In2 のゾーンを KiCad 7 で再充填して保存した。

**配置の決め方**
- `tools/placesearch_c34.py` で候補を探した。
  - 0.05mm 刻みで位置を振り、向き2通りを試した。
  - F/In1/In2/B の各層について、クリアランス 0.2 と穴間隔 0.25 を確認した。
  - U2 左の制御線の予約領域（F: x41.2–45.5 × y42.1–44.1、B: x32–44.6 × y35.8–44.05）は候補から外した。
- その中から、3V3 の接続点が U2.58 の内周ビア (46.05,43) に最も近い案を選んだ。

**検査結果（実測）**
- KiCad 7 DRC のエラー（短絡、クリアランス、穴間隔、配線端・ビアの未接続）：0件。
- 未接続：112件 → 110件。
  - ネット単位の変化は 3V3（14→13）と GND（31→30）だけ（`uncmp.py`）。
- シルク関係の警告件数は変わらない：silk_overlap 26、silk_over_copper 67、text_height 135。
- 電源監査（`audit_sync_in_k7.py`）：電源75件・GND80件の検査がすべて PASS。
  - 残りの FAIL は U2 の再ピン割当によるものだけ（CLAUDE.md の課題5・課題9）。
    - `circuit_manifest.json` の U2 のピンネットの不一致：33件。
    - `sync_out_progress.json` の旧ピン U2.60/61 → R41/R42：2件。

**未検証**
- パスコンとしての効果。C34 は U2.58 から面経由で約4.6mm 離れている。PDN の評価はしていない。

**基板ファイル**
- sha256（先頭16桁）：6c5330aaddf31f70

## 2026-09-28 課題2：プルアップ／プルダウン R37–R40（0402 化）

**判断**
- 利用者の判断で、R37–R40 を 0603 から 0402（R_0402_1005Metric）へ変更した。定数は変えていない（R37/R38 2.2k、R39/R40 10k）。
- 理由：信号ビアを置ける F.Cu の空きが x 37.2–39.9 に限られ、0603 では4本中2〜3本しか収まらなかった（`tools/pullsearch.py` の探索結果）。

**変更内容**
- 4本を縦置きにし、0.95mm ピッチで並べた：R40 (37.2,37.7)、R39 (38.15,37.85)、R37 (39.1,37.55)、R38 (40.05,37.05)。pad1（信号）が下。
- 信号ビアは各ネットの B.Cu 斜め配線の上に置き、F.Cu の短い配線でパッドとつないだ。
- 面へのビア：
  - 3V3 は R40 用 (37.2,36.2) と R38 用 (40.05,35.75)。R37 は R38 の 3V3 パッド経由でビアを共用。
  - GND は R39 用 (38.35,36.2)。当初案の (38.15,36.2) は REF_27M のビアとのクリアランスが 0.146mm で違反したため移した。
- 参照番号のシルクは 0.5mm の文字で、右側の空き (41.55, 36.0–38.55) に縦一列でまとめた。
- 回路図 `06_support.kicad_sch`（Footprint 欄とインスタンス行）、`amiga_scandoubler.net`、`circuit_manifest.json` のフットプリントを 0402 に更新した。KiCad 7 の `kicad-cli sch export netlist` で読み込めることを確認した。

**検査結果（実測）**
- KiCad 7 DRC のエラー：0件。
- 未接続：106件 → 98件。
  - 変化：3V3 13→10、GND 30→29、ADC_PWDN / ADC_RESET_N / I2C_SCL / I2C_SDA 各 1→0。
- シルク関係の警告：silk_overlap 26→25、silk_over_copper 67→66。
- 導通の確認：
  - 各プルアップの pad1 と、U1・U2 の該当ピン。
  - R37/R38/R40 の pad2 と 3V3（C56）、R39 の pad2 と GND（U2 EP）。
- 電源監査：電源75件・GND80件 PASS。残りの FAIL は前回と同じ（U2 再ピン由来の35件）。
- `scripts/pull0402.py` を前版に適用し、同じ DRC 結果を再現できることを確認した。

**未検証**
