# TVP7002起動設定候補 v0.7

2026-09-11。`tvp7002_boot.sv` は起動待ち、36件のレジスター書き込み、ALC待ち、設定状態の保持を接続した。Amiga実機で校正したPAL/NTSCプリセットではない。

## 起動と失敗処理

27MHz発振器から動作する。電源安定待ち5ms、RESET保持10µs、解除後1msを経て、7bitアドレス5Chへ設定を書き込む。最初に17h=03hでADC出力を無効にし、最後に17h=02hで出力を有効にする。全件のACK後、ALC用に810,000基準クロック（27MHzで30ms）待つ。

全件の書き込み成功と待ち時間経過で `qualified_ref` が有効になる。これはクロック監視を開始してよいという意味で、レジスター読み戻し・ALC収束・映像同期の確認ではない。入力信号がなければ、30ms待っても黒レベルは調整できない。

`video_locked` は別途、映像クロックと水平・垂直同期の状態を確認し、27MHz側へ同期した信号を与える。設定済みで、かつこの信号が有効な場合だけ `video_allowed` が立つ。クロック監視へは `qualified_ref` を渡すため、ロック取得を互いに待つ循環はない。設定成功後に `config_allowed` が下がっても、設定済み状態は消えない。

通信失敗では `fault` を保持し、ADCをRESET/PWDN状態に戻す。`write_error` と `failed_register` に原因と失敗したレジスターを残す。自動再試行はしない。電源断または全体リセット後は先頭から設定し直す。PAL/NTSC設定などパラメーターを切り替えるときも全体を再起動する設計とし、実行中の書き換え機能は含まない。

## 候補値の根拠と調整点

| 対象 | 設定候補 | 意図・残る確認 |
|---|---|---|
| 入力選択 | 19h=00h、1Ah=CAh | 回路図のRGB入力1・HSYNC_A・VSYNC_A、27MHz基準、内蔵HPLLから標本化 |
| 同期 | 0Eh=12h、22h=04h、36h=02h | 外部H/V、H極性自動判定、5線入力向けcoast無効、VSのみ未加工で出力 |
| RGB形式 | 10h=58h、15h=00h、18h=00h | RGBの黒基準クランプ、4:4:4、色変換なし、データはDATACLK立ち上がりで更新 |
| HPLL | 01h→02hの順、03h=10h | 1ラインのサンプル数を上位から書く。36MHz未満の範囲、チャージポンプ値2を候補とする |
| 位相 | 04h=00hを初期候補 | 位相0。SuperHires等の細線を使って実機調整が必要 |
| クランプ/ALC | 05h=06h、06h=10h、31h=18h | H同期末尾からクランプを置き、その後にALCを置く。実入力のバックポーチ内に収まるか確認 |
| HS出力 | 07h=80h、21h=0Dh | 出力HS幅128標本。位相0でRGB遅延18クロックとHS遅延5+13クロックを名目上揃える |
| ゲイン | 1Bh=88h、1Ch=08h、08h～0Ah=19h | アナログ1.3倍・デジタル1+25/256倍。0.7V入力から約1.0V相当を狙う計算値で、白クリップと黒レベルの実測が必要 |
| ALC | 26h=80h、28h=33h | 有効、垂直係数1/64・水平16タップ。30msは初期待ちであり収束判定ではない |

H_SAMPLESは明示指定必須。試験では1816・1820・2048を用いた。1536～2048の偶数だけをこの候補回路では許可する。これらの数値をPAL/NTSCの完成設定として自動選択してはいない。Amigaの長短ラインを含む実際のライン長変動に対する処理も未実装。

VSの未加工出力はH出力と同じ取り込みタイミングとは限らない。後段ではメタステーブル対策、パルスの正規化、RGB/HSとの時間差補償が必要。H出力は未加工バイパスにしない。HとVSを無条件で同じ遅延として扱わない。

資料：[TI TVP7002 SLES206C、出力タイミング・各レジスター説明](https://www.ti.com/lit/ds/symlink/tvp7002.pdf)。値はこの基板構成に合わせた設計候補であり、TIがAmiga用に保証した設定ではない。

## 確認済み範囲

端子のSCL/SDAだけを観測する試験モデルで、デバイスアドレス・レジスター番号・データ・STOPを照合した。設定表は試験側に独立した固定値で持ち、DUT内部のROMや状態を合否判定に使っていない。

1816/1820/2048条件では各36箇所にデータNACKを挿入し、すべて停止・診断保持・出力抑止を確認。バス固定、設定途中の電源断、電源復帰後の全設定やり直し、ロック消失時に設定済み状態を保持する動作も確認した。1816条件では通信半周期135・ALC待ち810,000クロックでも再試験した。合計2,406件の完結したI²Cトランザクションを照合した。

試験クロックは時間短縮用の100MHzだが、検証対象の分周・待ち時間はサイクル数で指定し照合している。製品で27MHzへ接続した場合の待ち時間とは区別する。前段の電源待ち時間はこの統合試験では短縮している。電源処理単体の検証記録は `control_simulation_report.txt` を参照。

新規モジュールの合成・配置配線、実ADC通信、レジスター読み戻し、入力の同期判定、PLL・データ取り込みの位相、実機画質は未確認。
