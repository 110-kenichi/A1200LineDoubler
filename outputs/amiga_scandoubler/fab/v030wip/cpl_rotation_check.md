# CPL の回転チェック表（机上、2026-09-29）

JLCPCB の実装機は、各部品の **EasyEDA（JLC ライブラリ）のフットプリントの向き** を基準にする。
KiCad のフットプリントと基準が違うと、`jlc_cpl.csv` の回転のままでは部品が 90°・180° ずれて置かれる。
発注画面の **部品配置プレビュー** で、下の表の「ピン1の正しい位置」と一致するかを全数確認する。

- 基板の座標は KiCad の上面図（y は下向き）。「左上」などの方向は、上面から見て部品の中心から見た向き。
- JLC のプレビューも上面図なので、方向はそのまま比べられる（JLC の CPL の y は負の値で書かれているが、見た目は同じ）。
- J1/J2 は手はんだ（DNP 版の BOM/CPL を使う）なので、JLC のプレビューには出ない。

- U2 は基板上で180°回転している（v0.29 から）。プレビューで「右下にピン1」が正しい。

## 2. 向きの影響が小さい部品

- 抵抗・コンデンサ・インダクタ（0402/0603/0805、L_TDK_VLS4012CX）：極性がないので 180° のずれは問題ない。90° ずれるとパッドに載らないので、プレビューで見れば分かる。
- F1（PTC ヒューズ、1206）：極性なし。
- J1/J2：手はんだ。基板の端からコネクタの口が外を向き、四角いパッドが pin1（J1 は下側 (7.04, 46.31)、J2 は上側 (87.96, 37.69)）。

## 3. プレビューでずれていたときの直し方

- `jlc_cpl.csv`（または DNP 版の `jlc_cpl_dnp_J1J2.csv`）の Rotation を、ずれた角度だけ足し引きする。今の CPL には −90 のような負の値も入っているので、必要なら 0〜359 に直してから出す。
- JLC の発注画面で部品ごとに回転を直すこともできる。直した値はこの表に記録しておく。
