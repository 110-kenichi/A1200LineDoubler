# CPL の回転チェック表（2026-09-30、EasyEDA フットプリントと照合済み）

JLCPCB の実装機は、各部品の **EasyEDA（JLC ライブラリ）のフットプリント** を、CPL の座標と回転で置く。
KiCad のフットプリントと向きや原点が違うと、KiCad の位置データ（`cpl_raw.csv`）のままでは 90°・180° の回転や、位置のずれが起きる。

## 照合の方法（実測）

- `work/v030wip/w30/tools/jlc_rotcheck.py`：部品ごとに EasyEDA のフットプリント（`https://easyeda.com/api/products/<LCSC>/components`）を取り、KiCad のフットプリントとパッド番号ごとに位置を比べた。
  - 0/90/180/270° のうち、パッドが重なる回転 R を求める（上面から見て反時計回り）。JLC に渡す回転 ＝ KiCad の回転 ＋ R。
  - JLC は EasyEDA の原点を CPL の座標に置くものとして、位置のずれも計算した。
  - 結果は `jlc_rotation_check.json`。
- 符号の確認：TQFP/LQFP の +270°、SOT-23-6 の −90°（＝270°）は、kicad-jlcpcb-tools の既定の補正表（matthewlai/JLCKicadTools）と一致した。
- 対象：JLC で実装する137点すべて（J1/J2 は手はんだ）。2026-09-30 に L1〜L3 を C92959 に替えたので、全137点を照合できた。

## `jlc_cpl.csv` / `jlc_cpl_dnp_J1J2.csv` に入れた補正

`scripts/r10_fab.py` が、`jlc_rotation_check.json` の補正を自動で当てる（パッドの一致誤差が 0.3mm 未満のものだけ）。KiCad の生の値は `cpl_raw.csv` に残っている。

| 部品 | パッケージ（EasyEDA） | KiCad 回転 | JLC 回転 | 位置の補正 | パッドの一致誤差 |
|---|---|---|---|---|---|
| U1 | HTQFP-100 | 0 | **270** | なし | 0.050mm |
| U2 | QFN-88 | 180 | **90** | なし | 0.050mm |
| U3 | LQFP-48 | 0 | **270** | なし | 0.087mm |
| U4, U5 | SOT-23-6 | 0 | **270** | なし | 0.012mm |
| U6 | SOT-23-5（ピン1が右下の版） | 0 | **180** | x −0.033mm | 0.195mm |
| U7–U9 | WSON-8 | 0 | 0 | なし | 0.000mm |
| Y1 | OSC 3225 4パッド | 0 | 0 | なし | 0.090mm |
| J3 | USB-C TYPE-C-31-M-12（長穴 0.8mm 版） | 0 | 0 | **y 方向 1.571mm**（基板の内側へ） | 0.000mm |
| J4 | 2×5 SMD ヘッダ | 90 | **0** | なし | 0.165mm |
| R/C/FB/F1 | 0402/0603/0805/1206 | — | 変更なし（−90 は 270 と表記） | なし | 最大 0.088mm |

- 2端子の部品は、0°と180°のどちらでもパッドが重なる。90°ずれるものは0件だった。
- J3 は、EasyEDA の原点がパッドの中心から 1.571mm ずれている。補正しないと、基板の外側（下）へずれて置かれる。
- 非公式の補正表では J3 は +180° とされているが、今の EasyEDA のフットプリントとは 0° で完全に一致した（誤差 0.000mm）。照合の結果を採用した。

## JLC のプレビューで確かめること（利用者側）

補正は計算上のもの。発注画面の部品配置プレビューで、次の「ピン1の正しい位置」と一致するかを全数確認する（上面図。方向は部品の中心から見た向き）。

| 部品 | ピン1の正しい位置（基板座標、y は下向き） | 向き |
|---|---|---|
| U1 | pin1 (18.35, 36.00) | 左上 |
| U2 | pin1 (54.95, 46.20) | **右下**（基板上で 180° 回転している） |
| U3 | pin1 (69.84, 39.25) | 左上 |
| U4 | pin1 (15.86, 58.05) | 左上 |
| U5 | pin1 (80.86, 54.05) | 左上 |
| U6 | pin1 (65.86, 53.05) | 左上 |
| U7 / U8 / U9 | pin1 (24.05 / 46.55 / 69.05, 72.25) | 左上 |
| Y1 | pin1 (38.85, 27.95) | **左下** |
| J3 | A1 (44.25, 87.31) | 左上。差し込み口が基板の下端に来る |
| J4 | pin1 (42.42, 12.53) | 左下 |

- **L1〜L3**（Taiyo Yuden NRS4018T2R2MDGJ、C92959）：EasyEDA と照合済み（R=180、極性がないので 0° と同じ）。
- ずれていたら、発注画面で部品ごとに回転を直すか、`jlc_rotation_check.json` の R を直して `r10_fab.py` を再実行する。

## J1/J2（参考。手はんだなので発注には関係しない）

- EasyEDA のフットプリント（C711364）は、信号ピン1〜15の並びがこの基板のフットプリントと同じだった。ピンの左右の向きが規格どおりであることの独立した裏付けになる。
- 違いは2点：固定金具の番号（EasyEDA は 16/17、こちらは両方 16）と、ピン3の位置（EasyEDA は固定穴の中心線上、こちらはデータシートと KiCad 標準に合わせて 0.265mm ずらしている）。
- JLC に J1/J2 も実装させる場合は、この 0.265mm の違いがあるので、プレビューで位置を確認する。
