# v0.8 入力同期前段の追加

2026-09-11 / 開発版・製造用ではありません。

既に取り込み済みのADC画素・HSと、非同期のVSを受ける前段を追加した。水平周期の連続確認、VSの同期化と短パルス除去、フィールド周期の確認、同期断後の再取得を行う。映像処理核へ接続し、同期無効時の出力抑止と復帰を試験した。

前段7条件と統合1条件を `stream_simulation_report.txt` に記録する。524～626半ラインの各フィールド周期、奇数周期による半ライン位相、VS遅延値0/7/31、32および1816サンプルのライン長を含む。統合試験では121,176有効画素を入力時刻から独立に計算して照合した。

今回の変更は `stream_sync_frontend.sv`、`stream_input_video.sv`、試験、説明資料。既存の映像処理核、ADC起動設定、クロック監視、回路・配置は変更していない。基板案は95×95mm・135部品・129ネット、未配線のv0.6を引き継ぐ。

実ADCの入力レジスター、PLL、VS位置校正、長短ラインの連続表示への対応は未完了。新規前段の合成・CDC・タイミング確認も未実施。詳細は `stream_input.md`。

レジスター読み戻し、基板用トップ回路、FPGA実装確認、部品確定、基板配線、Gerber・製造BOM・CPLの作成が引き続き必要。実機で映像・消費電力・PSAVE動作を確認する工程も残る。
