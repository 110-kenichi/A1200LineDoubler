# 入力ストリームの同期前段 v0.8

2026-09-11。固定ライン長のデジタル前段と、映像処理核への接続を追加した。ADC端子の物理的な取り込み回路やPLLを実装したものではない。

## 入力条件

`stream_sync_frontend` の `clk` はサンプル周波数の2倍。`sample_ce` は必ず1クロックおきに有効にする。`rgb_sampled` と `hs_n_sampled` は、このクロックに対して既に取り込み条件を満たした信号を渡す。ADCの24bit RGBを各bit別々の2段同期器へ通してはいけない。入力レジスターとPLL位相・タイミング制約によってバスとして取り込む処理が別途必要。

VSだけは `vs_n_async` で受け、2段同期器と連続レベル確認を通す。H/VはともにLow有効を前提とする。v0.7のADC設定候補では、HSは処理済み出力、VSは未加工バイパス出力なので、同じ経路の信号として扱わない。

## 実装した動作

- RGBとsample_ceは1クロックの同じ段を通す。HSの立ち下がりをsample_ce時に検出し、同じ段でline_startを出す。
- H周期が2×H_SAMPLESクロックで3区間続いてから水平同期を許可する。周期違い、HS消失、sample_ceの交互動作違反は許可を取り消す。
- VSは既定で4クロック連続してレベルが変わった場合に採用する。短いパルスは捨てる。
- VSの最初の有効エッジは周期測定の基準にする。次のエッジまでが500～660半ライン分の範囲ならフィールド開始を出す。フィールド番号や前フィールド画像は保存しない。
- VS周期が短すぎる場合、または最大待ち時間まで次のエッジが来ない場合は垂直同期を無効にする。H/Vを再取得すると自動復帰する。

`fault_history[0]` はsample_ce異常、bit 1はH周期異常、bit 2はV周期異常。履歴は全体リセットまで保持する。履歴が残っていても、同期の再取得は行う。

`stream_input_video` はこの前段を `video_core` へ接続する。同期無効時は映像処理核をリセットし、RGBとBLANKを出力抑止側にする。同期が回復した場合も、ラインの蓄積と出力同期の開始を待って表示する。

## VS位置の調整

`VS_ALIGN_CYCLES` は明示指定必須。フィルターで有効と判断したVS立ち下がりから、さらに指定クロック数を遅延してフィールドイベントを出す。デジタル試験で、VSがクロック間に変わってから判定されるまでの遅延は、4クロックフィルターと2段同期器で5クロックとなる位相条件を用いた。実際の非同期入力ではクロック位相による量子化差がある。

試験のALIGN=0・7・31は、遅延回路そのものを確認する値。実基板用の確定値ではない。ADCのRGB/HS遅延、VSバイパス経路、入力レジスター、PLL位相の分を含めて決める必要がある。フィールドイベントが出力ライン境界の前後を跨ぐと、後段の整列処理で開始位置が1出力ライン変わり得る。この境界付近のジッター対策と校正は未完了。

## 既存モジュールとの接続

基板用トップ回路では `video_clock_guard` を1個置き、その `reset_video` を本前段へ渡す。画素処理には `stream_input_video` を使う。`supervised_video_core` は前版の試験用接続例なので、これを直列につないで画素処理核を二重にしない。

クロック停止中にも出力を抑止するため、基板用トップでクロック監視の許可とRGB/BLANK/H/Vを結合し、DAC PSAVEも接続する。ここで追加した前段は停止したクロックでは動けないため、常時動作する監視回路の代用にはならない。`sync_valid` を27MHz制御側へ返す場合も同期化が必要。

## 試験と残る制限

524・525・624・625・626半ラインの周期、半ライン位相、短いVSパルスの除去、VS消失、HS消失、sample_ce異常、短すぎるフィールド周期、各異常からの復帰を試験した。32サンプル条件に加え、1816サンプル条件でも前段を確認した。試験記録は `stream_simulation_report.txt`。

映像処理との接続試験では、入力時刻から出力画素を独立に計算し、121,176有効画素のRGBと同期無効時の出力抑止を確認した。実ADCのアナログ信号やメタステーブル現象を模した試験ではない。

現在は固定ライン長だけを扱う。長短ラインは再取得の原因として検出するだけであり、Amigaの長短ラインを連続表示する処理は未実装。この条件のまま全Amigaモードへの対応を宣言しない。新規前段の合成、CDC静的検査、配置配線、実機取り込み位相・画質の確認も残る。

## v0.9 取り込み回路の追加

`adc_rgb_capture` に入力レジスターと更新トークンの受け渡し候補を追加した。PLLの設定候補と実装時の制約は `pll_capture.md`。データ経路は関連クロックとしてタイミングを満たす必要があり、実機で成立した取り込み回路としてはまだ扱わない。
