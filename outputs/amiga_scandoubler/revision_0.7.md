# v0.7 ADC設定シーケンスの統合

2026-09-11 / 開発版・製造用ではありません。

電源起動処理とI²C書き込みを接続し、TVP7002へ36件のRGB入力設定候補を順に送る処理を追加した。最後の書き込みとALC待ち時間を終えてからクロック監視へ許可を出す。失敗時はADCを停止し、原因とレジスター番号を保持する。

3種類のライン長条件で全36設定位置のNACK、バス固定、電源断・再起動を試験した。実用分周値と30ms相当のALC待ちサイクル数も試験し、計2,406件の完結したI²C通信を照合して通過。設定値そのものの実機妥当性を確認した結果ではない。

今回の追加は `rtl/tvp7002_boot.sv`、試験、`adc_configuration.md`。既存RTLと回路・配置は変更していない。基板案は95×95mm・135部品・129ネット、未配線のv0.6を引き継ぐ。過去の試験・合成結果はそれぞれの対象に限る。

残る主要作業は、レジスター読み戻し、PLL・ADC取り込み、入力同期判定と長短ラインへの対応、基板用トップ回路、FPGA実装タイミング確認。その後に基板配線、部品確定、製造用Gerber・BOM・CPLを作成する。実機で位相・ゲイン・クランプ窓・PSAVE動作を調整・確認する必要がある。
