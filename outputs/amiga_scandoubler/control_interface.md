# ADC起動・通信処理の接続条件

v0.3 / 2026-09-09。以下はテスト済みの部分モジュール。ADC初期値テーブルや書き込み済みビットストリームではない。

## 起動制御

`rtl/adc_power_sequence.sv`はADCのクロックがまだ出ていない時点から動く必要があるため、基板の27MHz発振器で駆動する。

1. `power_good`が安定してから5ms待つ。
2. PWDNを解除し、RESETBを低いまま10µs保持する。
3. RESETBを解除し、さらに1ms待って`config_allowed`を立てる。
4. 設定終了通知`config_done`を受け、かつ外部から`video_locked`が来た場合だけ`video_allowed`を立てる。

これらの待ち時間は27MHz用の既定値。メーカー資料では電源安定後にRESETBを少なくとも1µs保持する条件がある。1msの待ち時間だけでPLLロックしたと判断してはいけない。`video_locked`は別途同期判定を行った27MHzドメインの信号を接続する。

電源状態は内部2段で同期化している。電源低下を検出すると待機状態からやり直す。通信エラーは故障状態を保持し、リセットまたは電源再投入で解除する。設定結果の通知は今回の起動について生成し、以前の`config_done`を残してはいけない。

## I²C書き込み

`rtl/i2c_register_write.sv`はアドレス、レジスター番号、データの3バイトを書き込む。端子はオープンドレインにする。`scl_low`／`sda_low`が1ならLow、0なら高インピーダンスとし、3.3Vへのプルアップは基板上の抵抗を使う。

```systemverilog
assign I2C_SCL = scl_low ? 1'b0 : 1'bz;
assign I2C_SDA = sda_low ? 1'b0 : 1'bz;
```

`scl_in`と`sda_in`には実際の端子レベルを戻す。内部2段で同期化する。`address`は7bitの`7'h5c`を指定する。送信時の先頭バイトは書き込みビットを付けた`8'hb8`になる。

`start`を`busy=0`で1サイクルだけ立てると、その時点の入力を保持する。`busy=1`の間の新規要求は受け付けない。終了時に`done`が1サイクル立ち、`error`が結果を示す。

| error | 結果 |
|---|---|
| 0 | 3バイトともACKを受信 |
| 1 | デバイスアドレスにNACK |
| 2 | レジスター番号にNACK |
| 3 | データにNACK |
| 4 | バス使用中、またはSCLが上がらないままタイムアウト |

既定の135サイクル半周期は27MHzで100kHz以下となる。SCLの実入力を確認するため、高期間には同期化分の余裕が加わる。タイムアウトは既定で約10ms。NACKではSTOPを送って終了する。線がLowに固定された場合は出力を解放して終了するが、物理的にSTOPが成立したとは報告しない。

## 統合時に必要な処理

- `config_allowed=0`の間はI²Cモジュールをリセット状態に保ち、起動前にSCL/SDAを動かさない。
- レジスター設定を順番に送り、全件が成功して初めて`config_done`を通知する。
- いずれかの書き込みでエラーが出たら`config_error`を通知する。自動で設定成功扱いにしない。
- 設定読み戻し、ADCの状態読み出し、PAL/NTSC判定、クロック・映像処理との接続は未実装。
- この処理は単一マスター専用。複数マスターの調停やバスクリアの9クロック出力は実装しない。

## 検証範囲

テストのADCモデルはI²C端子だけを観測し、実際の送信バイトとSTART/STOPを照合する。内部状態を参照して合否を出すものではない。正常書き込み、処理中の入力変更、3種類のNACK、クロックストレッチ、SDA固定、SCL固定、通信途中リセットを確認した。分周値6と135の両方で合格。

起動処理は電源未投入、待ち時間、設定前・ロック前の映像抑止、ロック喪失、電源低下、設定失敗、電源安定待ちのやり直しを確認した。実FPGAの合成・配置配線や実ADC通信の試験ではない。

参照：[TI TVP7002 SLES206C、I²C Host InterfaceおよびPower Up, Reset, and Initialization](https://www.ti.com/lit/ds/symlink/tvp7002.pdf)

## v0.6 接続時の補足

クロック監視を追加した。設定成功から作る `qualified_ref` と、ロック取得後に得る `ready_ref` を区別し、起動の循環待ちを作らないこと。詳細とDAC PSAVE端子の変更は `clock_integration.md` を参照。

## v0.7 起動シーケンスの実装

`tvp7002_boot` に設定候補の順次書き込みとALC待ちを実装した。`config_allowed` は設定開始に使い、ADCがRESET/PWDNになると通信処理をリセットする。設定完了で `config_allowed` が下がっても成功状態を保持する。最新の接続条件と試験範囲は `adc_configuration.md` を参照。
