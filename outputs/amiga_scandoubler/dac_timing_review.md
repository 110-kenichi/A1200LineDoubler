# DAC出力タイミングの調査 v0.18

2026-09-12。現行180度設定の配置後SDFから、RGB24本とBLANKの25出力を両プロファイルで追跡した。**出力タイミングは未承認。今回の数値は欠落モデルを含む構造上の推定で、動作不良の確定判定でも、保証されたslackでもない。**

## 部品の条件

ADV7125の3.3V仕様はsetup 0.2ns、hold 1.5ns、140MHz品のクロックHigh/Low各2.85ns以上。5V側のsetup値を混用しない。[Analog Devices Rev.D Table 4](https://www.analog.com/media/en/technical-documentation/data-sheets/ADV7125.pdf)

U6 SN74LVC1G17の3.3V±0.3V、−40〜85℃では、伝搬遅延は15pF試験で1.5–4.6ns、50pF試験で1.8–5.5ns。負荷条件はFigure 6-1/6-2に対応する。実基板の負荷は未算定のため、どちらも比較ケースであり実装値ではない。直列抵抗による波形・しきい値通過時間も別途必要。[TI Rev.Y §5.6–5.7、Figure 6-1/6-2](https://www.ti.com/lit/ds/symlink/sn74lvc1g17.pdf)

56.75MHzの周期は17.621ns、正エッジから反転DACクロックの理想立上りまでは8.811ns。下表の範囲はFPGA内部の起点クロック配線、FFのclock-to-Q、組合せ回路、出力バッファ入力までの配線を含む。端子の電気的遅延を含まない。

最長経路の起点は `logic_core.clocks.guard.release_pipe`。映像の画素経路より、起動・復帰時の表示許可経路が長い。静的に全経路を毎周期の変化として計算すると、同じ端子でsetupとholdの許容範囲が重ならない例がある。ただし表示許可が実際に変化する状況、PSAVEによる抑制、論理的に成立する経路をまだ検証していないため、通常表示時の確定違反として扱わない。

RGB画素FFだけの範囲にも出力マスクの組合せ回路を含む。画素だけの値が小さいことはBLANK、同期、異常時の出力を含む全体の合格を意味しない。

## 再現と計算式

`python implementation/analyze_dac_sdf.py` で `implementation/dac_timing_budget.json` を再生成する。プロファイルごとに25出力の最短・最長起点、RGB起点だけの範囲、各端子の条件、未モデル化端点、借用したLUT遅延、元SDFのSHA-256を記録した。

端子iごとに、X_iを「未確定のデータ側遅延 − 未確定のクロック側遅延」とする。クロック側にはODDR、SDFにない専用接続、出力バッファ、基板配線を含む。Dは抽出したデータ側推定値、Cは抽出できたクロック配線0.260ns、BはU6の比較ケース。定常状態・理想50%クロックで、必要条件は以下。

```
X_i,max <= T/2 + C_min + B_min - setup - D_i,max
X_i,min >= -T/2 + C_max + B_max + hold - D_i,min
```

各端子のXは異なるため、全出力を一つのXにまとめて判定しない。ODDR専用接続はSDFに存在せず、ゼロ遅延とはしていない。未知項に含める。

## 解析の限界と次の設計作業

- 小規模LUTのIOPATHが欠落している。入力番号が同じ他のLUT4の最小・最大を借用した推定であり、保証値ではない。
- ODDRとOBUFの出力遅延が欠落。配線遅延もSDFではmin/typ/maxが同一で、全PVTを保証しない。
- PLL LOCK、外部電源状態、別クロック領域、未追跡の定数／算術端点などは一覧に残し、成立する全経路を解析済みとはしていない。
- PLLジッター、クロック歪み、出力負荷、基板配線、実際のODDR波形・開始時パルスを含む最終確認は別途必要。

次は表示許可の解除から可視画素を出すまでの順序を検証し、RGB・BLANKの出力段を同期化する必要性を判断する。同期化する場合はH/Vとの位置関係、DACの1段パイプライン、クロック停止時のPSAVEを同時に確認する。クロックバッファの追加や遅延増加だけで解決しない。

今回、回路・部品・RTLは変更していない。95×95mm基板は未配線。Gerber、製造用BOM/CPL、実機用ビットストリームの完成版ではない。現行論理の再現手順は引き続き `implementation/phase180/`。
