# v0.3 起動処理・フットプリント更新

2026-09-09。製造前の検討版。

## 今回進んだこと

- ADCの起動制御とI²Cレジスター書き込みを実装し、自動テストを追加した。通信相手が応答しない場合も検査した。詳細は`control_interface.md`。
- GW1N-4 QN88用フットプリントを作成した。中央ランドはメーカー推奨の6.8mm角に訂正した。
- TVP7002の仮フットプリント指定を訂正した。9.5mm角の中央パッドを想定した指定を取りやめ、メーカーの放熱パッド図に基づく専用パターンを作成した。
- TPS62160の標準フットプリントをメーカー図面と照合した。
- 回路図のフットプリント参照を更新した。電気的な接続数は134部品・129接続のまま。KiCadの出力ネットリストで再照合した。

## 残る作業

ADC初期値テーブル、レジスター読み出し、入力同期判定、PLLと画素の取り込み、DAC出力を統合する必要がある。追加した2モジュールだけで映像は出力できない。FPGAへの合成・配置配線も未完了。

フットプリントは2部品を追加した段階で、コネクターを含む全品の確定には至っていない。サーマルビア・ペースト開口は基板と実装条件に合わせて詰める。USBコネクターや受動部品の注文型番も残る。

基板は未配置・未配線のため、発注用Gerber、BOM、CPLはまだない。`Amiga.pretty`は部品ライブラリーであり、配線済み基板の代わりにはならない。今回の検査結果は実機動作の確認を意味しない。
