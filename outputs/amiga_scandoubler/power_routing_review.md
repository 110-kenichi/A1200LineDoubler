# 電源部の部分配線 v0.21

2026-09-20。95×95mmの基板に、3系統の降圧電源、USB電源入口、起動順序の制御配線を追加した。**部分配線のレビュー版。製造用ではない。** 回路・部品数・FPGAのRTLは変更していない。

## 今回配線した範囲

- U7/U8/U9の入力コンデンサ、SWとインダクター、出力コンデンサ、VOS、帰還抵抗、PGND/AGND/EPの局所接続。
- USB VBUSの4接点からヒューズ入力まで。ヒューズ出力から3系統への5V分配とC54。
- USB CC1/CC2からそれぞれ5.1kΩのR25/R26、抵抗のGNDへの接続。USBデータ線は回路図どおり未使用。
- U7のPG、R33/R35、U9のEN。U8/U9のPGとR34。R33/R34への3.3V供給。
- In1.Cuの連続GND面。34本の貫通ビア、154本の配線区間。5Vの主配線幅0.8mm、分岐0.6mm、信号線0.2mmを使用。IC端子の引き出しは周囲のパッドとの間隔に合わせて細くした。これらは熱・電圧降下の最終保証値ではない。

入力コンデンサを電源ICへ寄せ、FB/VOSをSWの下側に分離して、出力コンデンサ側から電圧を検出する配置とした。電源の高周波ループを短くし、FB/VOSをSWから離す方針は[TI TPS62160データシート §11.1](https://www.ti.com/lit/ds/symlink/tps62160.pdf)に従う。実負荷の温度上昇・効率・リップル・電磁ノイズは未評価。GND面を追加したことだけで電源品質を保証しない。

## 接続・間隔検査

KiCad 7の実際の銅箔接続情報をたどり、57組の電源接続を確認した。USB GND、CC抵抗、R35、C54の計6接続がGNDビアへ到達すること、GNDビアが単一の内層GND領域内にあることも確認した。全部品135個・592パッドのネット割り当てを回路定義と照合し、不一致なし。

既定クリアランス0.20mm、ビア径0.60mm／ドリル0.30mmの条件で、今回のDRCは銅箔クリアランス、短絡、穴周辺間隔、部品コートヤードの重なり、未接続ビア、ソルダーマスクのブリッジを0件とした。検査を通すための除外登録や間隔規則の緩和は行っていない。

**基板全体のDRCは合格していない。** 未接続365件、文字高さ135件、シルクと銅箔の重なり72件、シルク同士の重なり27件、シルクと基板端の間隔2件が残る。未接続件数はKiCadのラッツネスト件数で、未完了ネット数や作業進捗率ではない。詳細は `hardware/power_routing_drc.txt`。

標準フットプリントの参照先もプロジェクトの `fp-lib-table` に追加し、127件あった「ライブラリ未登録」の警告を解消した。KiCad 7の標準ライブラリが必要。環境変数 `KICAD7_FOOTPRINT_DIR` は標準フットプリントのディレクトリを指す。専用フットプリントの製造図面との最終照合・実装可否の確認は引き続き必要。

## 開くファイルと再現

現在の部分配線は `hardware/amiga_scandoubler_routing.kicad_pcb`。同名の `.kicad_pro` を同梱した。旧 `amiga_scandoubler_placement.kicad_pcb` は未配線の配置原案として保存している。部品移動後の座標は `hardware/power_routing_report.json` が最新。以前の `placement_report.json` を現在の実装座標として使わない。

`power_routing_review.png/svg` は全体、`power_routing_detail.png` は電源部。プレビューではF.Cuが赤、B.Cuが青、In2.Cuが橙。GND面のIn1.Cuは配線を見やすくするため省いている。シルクの色だけをプレビューで濃くしたが、製造データの文字形状は変更していない。

KiCad 7付属Python（pcbnewが使用可能）で、次のスクリプトを実行できる。

```
python hardware/scripts/build_power_routing.py
python hardware/scripts/audit_power_routing.py
```

生成処理は未配線の配置原案から部分配線基板を再作成するため、手作業の配線を追加した後に実行するとその追加分を上書きする。現状を再現する場合だけ使う。監査だけなら後者を実行する。監査にはKiCad 7標準ライブラリの参照設定も必要。

## 残作業

電源ICからADC/FPGA/DAC各電源端子への分配、各ICのデカップリング、POWER_GOODからFPGAまで、RGB・クロック・同期・制御信号は未配線。電源部のシルクも未整理。USBの電源供給条件、必要電流、ヒューズの確定型番、コンデンサの有効容量・定格、実負荷の熱設計は未完了。

FPGAの現行実装はv0.20の `implementation/output_release/` のまま。入力プロファイル、長短ライン対応、外部タイミング、実機確認を含む未完了項目は残る。製造用Gerber、完成BOM/CPL、書き込み用ビットストリームはまだ生成していない。
