# v0.11 機能回路の全体接続

2026-09-12 / 開発版・製造用ではありません。

`amiga_logic_core` に、ADC起動設定、PLL再起動・監視、RGB/HS取り込み、同期確認、ライン倍化を接続した。初回起動から12,259回の有効RGB出力を照合し、ADC停止後の復帰、電源断、起動時の通信拒否による停止も確認した。

初期試験でADCクロック停止中のリセット条件の不足が見つかり、試験モデルに明示的なリセット入力を与えるよう修正した。実基板側の電源投入リセットを実装したものではない。詳細は `system_integration.md`。

PLLのクロックとLOCKは試験モデルであり、物理的なDACクロック転送も今回の範囲外。合成・配置配線・CDC・タイミング解析を経た完成FPGAではない。

既存RTLと基板データは変更していない。95×95mm、135部品、129ネットの未配線配置案を維持。基板用トップ、電源投入リセット、実PLL/DACクロック、読み戻し、長短ライン対応、VS校正、FPGA実装確認、基板配線、Gerber・製造BOM・CPLが残る。
