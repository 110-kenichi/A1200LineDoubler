# 基板端子への接続案 v0.13

2026-09-12。基板用トップ `rtl/amiga_board_top.sv`、設定直後のリセット生成、端子制約候補を追加した。実PLLと専用DDR出力をインスタンス化したが、配置配線・タイミング検証は未実施。書き込み用データではない。

## 見つかった端子制約と修正

Gowin GPIO資料 UG289-2.2.1E、4章冒頭の注意書きでは、GW1N-4のIOL10/IOR10端子はIO logic非対応となっている。従来DACクロックに割り当てた57番はIOR10Eであり、ODDRを配置する案には使えない。対応候補のIOL17Bへ移した。[メーカー資料、本文34ページ](https://cdn.gowinsemi.com.cn/UG289E.pdf)

|信号|旧FPGA端子|今回の端子|理由|
|---|---:|---:|---|
|DAC_CLK_RAW|57 / IOR10E|16 / IOL17B|専用DDR出力を使うため|
|ADC_PWDN|16 / IOL17B|57 / IOR10E|低速の省電力制御は通常GPIOで扱えるため|

省電力制御とクロックの外付けプル抵抗は、それぞれの信号ネットに接続したまま維持した。回路図、KiCadネットリスト、部品・ネット定義、端子表、配置基板を再生成。接続検査25項目が通過し、基板592パッドのネット照合は不一致0件。135部品・129ネット、95×95mmの外形を維持した。まだ未配線である。

新しい端子は上記の非対応端子群を避けているが、ODDRの実配置成功を確認したものではない。ADCのHS/VSやDACのBLANK/H/V/PSAVEに使うIOR10端子には専用IOレジスターを要求せず、通常GPIOとして扱う必要がある。

## 基板用トップの接続

`amiga_board_top` は物理信号62本を受け持つ。RGBは `{R[7:0],G[7:0],B[7:0]}` として既存処理へ渡し、同じ順でDACへ戻す。I²C端子はLow駆動と高インピーダンスだけを出力し、端子の値を読み戻す。診断信号は内部で終端し、余分な外部端子は増やしていない。

`constraints/amiga_board_top.cst` に端子位置、LVCMOS33、内部プルなしの候補を記載。外付けプル抵抗は回路図どおり使う。端子と基板ネットの対応は `constraints/board_port_map.json`、照合結果は `board_pin_audit.txt`。CST構文はGowinのIO_LOC/IO_PORT形式に従うが、実装ツールによる受理はまだ確認していない。[メーカー制約資料](https://www.gowinsemi.com/upload/database_doc/2/document/5bfcfd099cf5f.pdf)

## 起動リセット

`configuration_reset` は初期値0の32段シフトレジスターを使い、REF_27Mが32回立ち上がるまでresetを保持する。参照クロックが来なければ解除しない。この32クロックは既存ADC電源シーケンスの5ms待ちを置き換えない。

FPGA設定時のレジスター初期値とGSRの実装に依存する。初期値の保持を、実装後ネットリストと実機で確認する必要がある。外付けの電源監視回路を追加したわけではない。動作途中の基準クロック停止を検出する回路でもない。起動後のPOWER_GOOD低下は既存の電源シーケンスが処理する。

## DACクロックとPLL

v0.9の `gowin_video_pll` を実プリミティブ名で接続し、PLL再起動要求を既存の監視回路から渡す。DACクロックはODDRの定数入力D0=0、D1=1を使う反転位相の候補とした。通常の画素更新エッジから、DACの取り込みまでの余裕を取る目的である。Q0を直接DAC_CLK_RAW端子へ出し、論理ゲートでクロックを停止させない。停止時のDAC省電力制御は既存回路が担当する。

ODDRの接続条件とパラメーターは [UG289、4.3.1](https://cdn.gowinsemi.com.cn/UG289E.pdf) を参照。実際のODDR波形、クロック配線、基板上のU6バッファ遅延、RGB/BLANKの到着時刻、DACのsetup/holdをまとめて確認しなければ、位相の適否は決められない。固定位相を実機用の完成設定として扱わない。

## 今回の試験の範囲

`sim/run_board_tests.py` はリセット長2/32/65の境界、参照クロックの開始遅延・途中停止、ADCクロック停止・POWER_GOOD=0の条件で基板トップの出力を検査した。100参照クロックを通過。記録は `board_simulation_report.txt`。

この試験のPLLはクロック停止モデル、ODDRはインターフェースを成立させる簡易モデルであり、メーカーのプリミティブ・タイミングモデルではない。映像表示やDDR波形を検証した試験ではない。試験用モデルはsim側だけに置き、製品RTLには入れていない。既存の機能RTLは変更していないため、v0.12の機能回路合成結果はその範囲で引き続き参照できる。今回の基板トップの合成結果ではない。

## 次に必要な確認

選定デバイス・パッケージでの実装プロジェクト、設定兼用端子のGPIO解放、初期値とリセット経路、PLL/ODDRの配置、ADC入力・DAC出力の実遅延を含むタイミング制約が必要。未確定の値を埋めたSDCや、クロック間を一括して非同期扱いする例外は作成していない。

PAL/NTSCの実入力設定、長短ラインの連続処理、ADC設定の読み戻し、実測確認も残る。基板配線と製造用Gerber・BOM・CPL、ビットストリームは未完成。
